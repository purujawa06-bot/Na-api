# Security Policy 🛡️

## Supported Versions

Only the latest version of **Na-api** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes              |
| < 1.0   | ❌ No               |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public issue. Instead:
1. Contact the maintainer: **purujawa06-bot** via GitHub.
2. Provide a detailed description of the vulnerability and steps to reproduce.

We aim to respond within 48 hours and provide a fix within 7 days.
