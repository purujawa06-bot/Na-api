# Contributing to Na-api 🤝

Thank you for considering contributing!

## How to Contribute

1. **Fork** the repository.
2. **Clone** your fork: `git clone https://github.com/your-username/Na-api.git`.
3. **Create a Branch**: `git checkout -b feat/your-feature-name`.
4. **Make Changes**: Ensure code follows existing patterns.
5. **Lint**: Run `npm run lint`.
6. **Commit**: Use descriptive messages (e.g., `feat: add new ai provider`).
7. **Push**: `git push origin feat/your-feature-name`.
8. **Pull Request**: Open a PR against the `main` branch.

## Code Standards
- Use JSDoc for API route handlers to auto-generate documentation.
- Keep libraries in `lib/` and UI components in `components/`.
